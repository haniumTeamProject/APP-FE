# 폰트 라이선스

앱에 넣은 폰트의 출처와 허용 범위를 기록한다.
**이 리포는 공개(public)라서 `.ttf` 파일을 올리는 것 자체가 폰트 재배포에 해당한다.**
앱에 넣는 것(임베딩)과 파일을 배포하는 것은 서로 다른 권리라, 둘 다 확인해야 한다.

| 폰트 | 쓰는 곳 | 저작권자 | 라이선스 | 임베딩 | 재배포 |
|---|---|---|---|---|---|
| Ria Sans | 30sp 제목 | LOTTE GRS CO.,LTD. | `RiaSans_license.pdf` | 허용 | 허용 |
| Gothic A1 | 16sp·12sp 본문 | HanYang I&C Co.,Ltd. | SIL Open Font License 1.1 | 허용 | 허용 |

2026-08-14 확인.

## Gothic A1

SIL OFL 1.1이다. 전문은 [GothicA1-OFL.txt](GothicA1-OFL.txt)에 있고,
**OFL은 폰트를 재배포할 때 이 사본을 함께 두라고 요구하므로 지우면 안 된다.**

`res/font/`에서는 파일명을 `gothic_a1_regular.ttf`로 바꿔 넣었다.
안드로이드 리소스 이름 규칙(소문자·숫자·밑줄) 때문이며,
OFL이 제한하는 것은 폰트 **내부 이름**이지 파일명이 아니라 문제되지 않는다.

## Ria Sans

롯데GRS의 브랜드 폰트다. 폰트 파일 안에 라이선스 URL이 비어 있어
배포처에서 받은 [RiaSans_license.pdf](RiaSans_license.pdf)가 유일한 근거 자료다.
조건이 바뀌었는지 확인할 일이 생기면 이 문서부터 본다.

상표로 등록된 이름이므로 **폰트를 고쳐 같은 이름으로 배포하지 않는다.**

## 남은 일

앱 안에 오픈소스 라이선스 화면을 두지 않았다.
OFL은 폰트를 앱에 넣는 것 자체는 자유롭게 허용하므로 지금 배포에는 문제가 없지만,
스토어에 올릴 단계가 되면 설정 화면에 라이선스 고지를 넣는 것이 통상적인 처리다.
